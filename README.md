# 方块斗兽场 · MOB CRATE ARENA

开箱 · 爬塔 · 自走混战。以「MC 随机怪物对抗」类视频为灵感的网页游戏：用 CS:GO 式开箱获得经过数值魔改的 Minecraft 生物，组成阵容，在擂台上全自动混战，一路爬过主世界、下界、末地三幕，最终屠龙。

## 运行

```bash
npm install
npm run dev        # http://localhost:5199
npm run build      # 产物在 dist/，纯静态，可部署到任意静态托管或子目录
npm run preview    # 预览生产构建
```

## 玩法概览

| 模块 | 说明 |
|---|---|
| 开局 | 选择统领（史蒂夫/亚历克斯/村民/女巫，后三者需解锁）与难度（普通 + 不祥之兆 I~V，见下方「难度」），连开 3 个新手箱组成初始阵容 |
| 统领 | 每位统领有自己的统领技能（物品栏左侧，Q/E）、特色机制和专属宝物：史蒂夫布阵时砌墙垫土台、亚历克斯驯服并收服敌人、村民订购指定生物并雇佣铁傀儡、女巫每场都有免费药水。详见 `docs/DESIGN-depth.md` |
| 地图 | 每幕 13 层分支地图 + 首领：战斗、精英、事件、商店、营火、宝箱；第二、三幕可能出现「筛界裂隙」节点（筛界战斗 → 裂隙补给箱） |
| 第四幕（可选） | 击败末影龙后可以踏入裂隙进入「筛界」（2026 年公布的新维度）：全新的筛界生物、群系、维度规则「灵魂潮汐」和首领幽匿巨像；也可以直接凯旋 |
| 战场 | 每场随机抽取 3D 方块战场（24 种群系：草原、森林、河畔、丘陵、沙漠、雪原、沼泽、矿井、冰洞、下界荒地、灵魂沙峡谷、末地城、粉色草甸、甲壳荒原、白骨森林……），0–4 格高低差、障碍与特殊地表（脆冰会被踩碎、Ouch 水伤害外来者） |
| 布阵 | 在 3D 地形上拖动己方小队到蓝色部署区；悬停地面查看地形效果；战力评估提示强弱 |
| 战斗 | 全自动，固定步长确定性模拟；1×/2×/4× 倍速、暂停、跳过；镜头自动追踪，可拖动旋转/滚轮缩放 |
| 战利品 | 从 3 个主题补给箱中选 1 个开启（CS:GO 滚动开箱，开启前可以返回换箱；设置里可选完整/快速/跳过动画），精英额外选宝物；战斗还可能掉落物品，物品栏满了可以换掉旧的，商店里可以半价出售 |
| 联动与克制 | 10 种生物联动（袭击队伍、箭雨、冰原猎手、沙漠游骑、幽匿歌谣……）和 6 条天敌克制（狼猎杀骷髅、寒冷克制火焰……），闪电还能给苦力怕充能 |
| 事件链 | 跨层、跨幕的连续事件：流浪商人会报恩或报复、不祥旗帜引来伏击、末影人回礼、裂隙中的歌声把歌者带到你身边 |
| 战斗物品 | 32 种一次性物品，战斗中从 Minecraft 式物品栏使用（点击或数字键，再点战场）：饮用/喷溅/滞留药水、风弹、蜘蛛网、岩浆桶、TNT（会误伤友军）、重锤、山羊角、冰球与冰冻药水、引雷三叉戟、长矛、烟花、蜂蜜块、末影珍珠、金苹果，以及召唤本场临时援军的刷怪蛋（含 1.21.9 的铜傀儡） |
| 成长 | 重复开出同一生物自动合成升星（★1→★2 需 1 张，★2→★3 需 2 张）；★3 解锁强化能力；品质越低每颗星收益越高；锻造最高把隐秘/特殊卡升到 ★2；附魔分 I/II/III 级，同名附魔书合成升级；附魔与升星都有预览确认；宝物里有 13 件「流派宝物」（燃烧、剧毒、数量、击退、爆破、高地、献祭、冰冻、末影闪现、复生、灾厄、坦克、雷电）；每位统领的三个新手箱卡池不同 |
| 生命 | 普通战败 -1 心，精英/首领 -2 心；首领战败可带伤重试（首领保留你造成的一半伤害） |
| 难度 | 参考杀戮尖塔的「进阶」：不祥之兆 I~V 每一级保留之前的全部规则再加新规则，敌我两边交替加压，而不只是加数值（见下表）；每级敌人生命再 +3%、攻击再 +2%，同时开箱幸运 +2%、得分 +20%。通关解锁下一级，并按统领记录最高通关难度（铜 I–II · 银 III–IV · 金 V 统领边框，另有每级的通关成就） |

| 不祥之兆 | 主题 | 新增规则 |
|---|---|---|
| I | 精英出没 | 地图上精英战更多，第 3 层起就会出现 |
| II | 精英词缀 | 精英战的敌人带一个随机词缀：再生、荆棘、迅捷、坚韧或嗜血 |
| III | 物资紧缺 | 开局少 1 颗心、物品栏 -1、商店 +15%；普通战斗中一张敌方卡牌带 II 级附魔 |
| IV | 精锐护卫 | 休息只回复 1 颗心；精英战和首领战中也有一张敌方卡牌带 II 级附魔 |
| V | 末日 | 首领生命低于一半时狂暴（攻速 +30%、受到伤害 -15%）并召唤一队护卫 |
| 经典对决 | 还原视频玩法：红蓝双方轮流开箱 3~5 轮后自动混战，可竞猜胜负 |
| 局外 | 图鉴、成就、对局记录、统领与难度解锁 |

**品质（CS:GO 配色）**：军规级（蓝）→ 受限级（紫）→ 保密级（粉）→ 隐秘级（红）→ 罕见特殊 ★（金）。品质越高单体越强、数量越少。开箱有升档几率（统领/宝物）和保底（连续 8 次未出红/金后几率递增）。

**羁绊**（按出战队伍中不同生物计数）：亡灵、节肢、灾厄、下界、末影、构造体、野兽、水生、史莱姆、筛界，各有 1~3 层效果。

**地形**：高地让远程「居高临下」（射程/伤害提升），攀爬缓慢（蜘蛛除外）；水、雪、泥沼、灵魂沙、蜘蛛网减速；岩浆灼烧非免疫生物；树木/岩石/柱子阻挡移动，生物用流场寻路自动绕行。群系加持：雪地的雪傀儡等攻速提升、沙地尸壳攻击提升、水中水生生物加速回血、末影人碰水受伤。为避免「无敌」情形：地形保证连通、高地可攀爬、加成有上限、飞行单位会进入近战范围。

**3D 玩法**：战场的第三个维度会直接影响战斗。
- **视线与掩体**：树木、岩石、柱子和山坡会挡住箭矢、火球等投射物。远程单位只在视线畅通时开火，被挡住时会换位置或换目标，久攻不下就逼近，所以掩体只能拖延，不会造成「打不死」。潜影弹（追踪）和首领的攻击不受遮挡。
- **摔落**：被击退摔下 2 格以上的高台，落地损失 5%～15% 最大生命并短暂眩晕；山羊 AI 会专门把敌人顶下高台或顶进岩浆。
- **建造**（史蒂夫）：布阵时就能在我方半场砌墙、垫土台。墙会改变寻路和视线（我方投射物可以越过自己的墙），不能把路完全堵死；土台上的远程会坚守高台；紧挨己方墙或站在土台上的友军受到伤害 -20%。
- **地形破坏**：苦力怕、TNT、恶魂火球、凋灵等爆炸会炸飞树木岩石、把高地削低 1 格。破坏有严格上限：半径不超过 2 格，每次最多削低 3 格，每场最多 24 个弹坑；最外圈、黑曜石和液体不会被破坏，地面不会低于 0 层。破坏只会让地形更开阔，不会把路堵死。每场战斗都在独立的地形副本上进行，重打时地形复原。

**打击感**：受击时先闪白再泛红并后仰，冒出原版风格的暗红伤害爱心，暴击迸出星星；血条带「伤害残影」（白色缓降段）；重击和大型单位阵亡时有短暂的顿帧；生物死亡掉出经验球。

**生物立绘**（`battle3d/sprites.ts`）：战场上的生物是卡牌立绘做成的「纸片人」，立在 3D 方块地形上。除了建筑类，每种生物都有七帧姿势——站立（卡牌立绘本身）、左右两步迈步、攻击（拉弓、挥斧、扑咬、吐火、施法、膨胀……）、受击、背面站立和背面行走——由图像接口以卡牌立绘为参照编辑生成，角色、比例和站位保持一致；走路时两条腿交替迈步、和每一步的弹跳同步，背对镜头走远时换成背面，攻击时切到攻击帧，被打时缩一下，倒下前先受击；飞行单位不停扇翅 / 摆动触手，史莱姆起跳落地各有一帧，苦力怕点燃引信、犰狳缩成球、潜影贝合壳也用对应的帧。设置里的「动画帧数」可以选高（7 帧）、中（3 帧：站立、迈步、攻击）、低（只用卡牌立绘）：帧数不影响每帧的渲染开销，只影响下载和显存（每种生物约 145 KB / 4.7 MB、64 KB / 1.8 MB、20 KB / 0.3 MB）。每种生物一个实例化的细分面片，由顶点着色器做弯折、挤压和拉伸：走路时每一步轻跳、落地压扁、身体前倾；站着时呼吸、轻轻摇摆；近战前冲拉伸，远程射击后坐；受击后仰抖动；死亡向后倒下压平；转身时像纸片一样对折翻面；飞行单位悬浮倾斜，史莱姆跳跃时压扁拉伸。光照跟随群系：天空色从上方、地面反光从下方轻微染色，脚底压暗，迎着太阳的边缘有一圈阳光描边、背光一侧稍暗；每个立绘会朝背离太阳的方向投下剪影阴影，走路时脚下扬起尘土。立绘写入深度，能被树木、山坡正确遮挡；一种生物的整支小队只需一次绘制（150 个单位时每帧 CPU 约 0.3 ms）。还藏了几个原版彩蛋：Dinnerbone / Grumm（倒立）、jeb_（彩虹）、名叫 Johnny 的卫道士。

**生物 AI**（`battle/tactics.ts`，双方通用）：远程会在射程内抢占高地、射完一箭就后撤拉开距离（拉扯）、尽量待在己方前排身后；残血单位会退回治疗者或回血区；近战冲向远程时会左右蛇形走位；所有非首领单位会对预警技能（苦力怕点火、唤魔者尖牙、恶魂/女巫的落点、火焰区域）做出闪避反应，反应几率按角色区分（坦克慢、刺客快）；坦克与辅助优先「掩护」被攻击的己方后排；范围攻击瞄准敌人密集处；山羊优先把敌人撞进岩浆/水里/高台下，唤魔者尖牙与监守者音波沿敌人最多的直线释放，嘲讽与咆哮等敌人聚拢再放。关键决策会在头顶显示小字（掩护!、抢占高地、后撤、闪避!）。每一项都用 A/B 基准验证过：同阵容镜像对战中，新 AI 对旧的「就近攻击」AI 胜率约 62–66%；集火、优先残血、目标粘性等在本模拟里反而输得更多，因此没有启用。

**防看懵**：关键词（中毒、凋零、居高临下……）高亮并可悬停查看释义，生物/宝物提示框附带关键词说明；关键界面有一次性新手提示（设置中可重置）；图鉴新增「玩法说明」页。

## 内容规模

- 55 种可开出的生物（14 蓝 / 15 紫 / 14 粉 / 8 红 / 4 金）+ 召唤物与 5 个首领（劫掠兽、远古守卫者、凋灵、末影龙、幽匿巨像），每种都有专属机制与 ★3 强化；其中 1.21–2026 的新生物有沼骸、犰狳、嘎枝（与嘎枝之心）、骆驼尸壳（驮着焦骸）、焦骸、硫磺立方、冰封僵尸，筛界生物有小筛者、噗噗、须筛者、筑巢者、高筛者、萌芽、幽匿斩击者、歌者（召唤回响傀儡）、幽匿舞者
- 4 位统领，各有统领技能、特色机制和 3–4 件专属宝物
- 9 种主题补给箱、22 种附魔（I–III 级）、32 种战斗物品、66 件宝物（含 6 件带代价的首领宝物、13 件流派宝物、14 件统领专属宝物）
- 4 幕（第四幕可选）· 89 个遭遇、29 个随机事件（含 4 条事件链）、19 个成就；10 种联动、6 条克制

  subset-font.mjs   按源码实际用字裁剪像素字体（~38 KB）

## 数值平衡工具

```bash
npm run bot -- 300 steve 0      # 300 局机器人：总胜率、每幕死亡分布、各类战斗胜率、首领首战胜率、有/没有红卡的通关率
npm run bot -- 300 steve 0 --no-build --seed 5000   # A/B：关掉史蒂夫的建造（另有 --no-golem / --no-order），换一批种子
npm run bot -- 200 alex 0 --sift  # 打败末影龙后进入第四幕筛界，额外统计筛界通关率
npm run sim -- cards 8000 1     # 随机 3v3，估计每张卡的强度
npm run aibench -- 400          # 战斗 AI A/B：新旧 AI 胜率、战斗时长、镜像对战的阵营偏差、每步耗时
```

当前基准（策略较笨的机器人会使用物品，双方均为战术 AI，含视线/摔落/地形破坏）：

| 难度 | 普通 | 不祥之兆 I | II | III | IV | V |
|---|---|---|---|---|---|---|
| 机器人通关率（史蒂夫） | ~45% | ~40% | ~33% | ~26% | ~20% | ~12% |

（两组种子各 400 局的平均；每升一级通关率下降 5–8 个百分点。旧版是 44 / 30 / 24 / 13 / 11 / 1，第 I 级和第 III 级是断崖，第 V 级几乎打不过。）

普通难度下四位统领的通关率约为：史蒂夫 40%、亚历克斯 42%、村民 49%、女巫 40%；第一幕阵亡率约 10%，首领首战胜率约 82% / 68% / 42%（史蒂夫）。进入可选的第四幕后，约 55% 的局能打败幽匿巨像。真人玩家（会搭配羁绊、站位、用药）明显更高。调整难度规则后用 `npm run bot -- 400 steve <等级>` 和 `--seed 5000` 两组种子复测，单组 400 局的波动约 ±4%。

## 美术管线

生物、图标、补给箱、场景均由 `gpt-image-2.5-flare`（quality=high，透明背景）生成，经 sharp 裁边压缩为 webp/jpg（全部约 4.4 MB，按需加载）。重新生成：

```bash
# 在 .env.local 中配置 IMAGE_API_KEY（该文件已被 .gitignore 忽略，不会进入构建产物）
npm run gen:images -- --only mob_zombie --force
npm run process:images
npm run gen:frames -- --mob zombie --force --concurrency 40   # 战场姿势帧：以卡牌立绘为参照编辑出迈步、攻击、受击、背面等帧（姿势描述在 scripts/frame-manifest.mjs）
npm run process:frames                                       # 同一生物的各帧用同一个裁切框对齐，打包成 public/assets/sprites/<生物>.webp（7 帧）和 <生物>_lite.webp（3 帧）
```

## 扩展内容

- **新生物**：在 `src/data/mobs.ts` 添加定义，在 `src/battle/ai.ts`（或 `ai-modern.ts`）添加行为（可选），在 `scripts/asset-manifest.mjs` 加提示词生成立绘、在 `scripts/frame-manifest.mjs` 写迈步和攻击姿势（受击、第二步、背面按体型自动生成）生成战场帧，再放进 `src/data/crates.ts` 的卡池。
- **新联动 / 克制**：`src/data/combos.ts`（触发后在 `SidePlan.flags` 里是 `combo_<id>`，在 `ai.ts` / `sim.ts` 里用 `b.has(team, 'combo_<id>')` 判断）。
- **新群系**：`src/battle/terrain.ts` 的 `BIOMES`（地表/地物在 `S`/`F`，渲染在 `battle3d/world.ts` 与 `textures.ts`）。
